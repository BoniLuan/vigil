What it does

Small surface.
Serious foundations.

Vigil keeps the product focused while giving scheduling, network security, persistence, and deployment the attention production software deserves.

01
↗

Endpoint monitoring

Scheduled GET and HEAD checks capture availability, HTTP status, latency, TLS expiry, and sanitized diagnostics.

02
⟳

Reliable execution

Bounded workers use durable identities, finite leases, crash recovery, and duplicate-safe completion.

03
⌁

Historical health

Threshold-based state transitions and rolling uptime summaries turn checks into useful operational context.

04
◫

Full-stack visibility

Prometheus, Grafana, Node Exporter, and cAdvisor cover application, host, and container health.

Architecture

One codebase.
Clear runtime boundaries.

The same hardened Go image runs the API, worker, and migrations as separate processes. PostgreSQL remains the authoritative datastore and coordination layer—no broker or in-memory scheduler required.
