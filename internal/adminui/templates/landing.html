What it does

Focused monitoring without unnecessary machinery.

Designed for a single Linux VPS today, with clean boundaries that can evolve when measured requirements justify it.

01

Endpoint monitoring

Scheduled GET and HEAD checks capture availability, HTTP status, latency, TLS expiry, and sanitized failure diagnostics.

02

Reliable execution

Bounded workers claim durable scheduled executions with finite leases, crash recovery, and duplicate-safe completion.

03

Current and historical health

Threshold-based state transitions, check history, and rolling uptime summaries make service behavior easy to inspect.

04

Full-stack visibility

Prometheus, Grafana, Node Exporter, and cAdvisor expose application, host, and container health without rebuilding existing tools.

Architecture

One codebase. Clear runtime boundaries.

The same hardened Go image runs the API, worker, and migrations as separate processes. PostgreSQL remains the authoritative datastore and coordination layer—no broker or in-memory scheduler required.
